PREPROCESSING REPORT
============================================================


1. OBJECTIVE
------------------------------------------------------------

The objective of preprocessing was to prepare a unified
YOLO object-detection dataset for ASTRA.

The final dataset contains normal traffic vehicles together
with emergency vehicles required for emergency-priority
traffic signal control.


============================================================
2. SOURCE DATASET - UVH-26
============================================================

Source:

UVH-26

Original training dataset:

21,349 images

Original vehicle categories:

14 classes

The original dataset was retained without modification.


============================================================
3. TRAFFIC DATASET SELECTION
------------------------------------------------------------

A controlled subset of 8,000 images was selected from the
UVH-26 training dataset.

Selection considered:

- Vehicle class diversity
- Traffic density
- Representation of different vehicle types
- Dataset coverage

The purpose was to create a manageable dataset suitable
for local YOLO training while retaining traffic diversity.

Output:

8,000 images

5. YOLO FORMAT PREPARATION
============================================================

The selected traffic images and annotations were prepared
in YOLO object-detection format.

Each annotation contains:

class_id
x_center
y_center
width
height

Coordinates are normalized between 0 and 1.

18. IMPORTANT PROJECT JUSTIFICATION
============================================================

The datasets were not directly used without processing.

The preprocessing workflow included:

1. Dataset inspection
2. Controlled image selection
3. Class consolidation
4. Class mapping
5. Annotation conversion
6. Removal of irrelevant classes
7. YOLO format preparation
8. Train-validation splitting
9. Visual annotation inspection
10. Dataset merging
11. Final annotation validation

This produced a unified dataset specifically designed for
ASTRA's 10-class vehicle detection requirement.
